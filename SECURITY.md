# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in ProfileForge, please report it via private GitHub Security Advisory or email security@profileforge.dev. Do not report security vulnerabilities through public GitHub issues.

We aim to review and respond to reports within 48 hours.
